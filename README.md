# Hi, I'm Jaxx

I write Python scripts that take boring computer work off people's hands. Mostly I clean up Excel and CSV files and collect data from websites. Sometimes I also build small tools that talk to APIs.

## Projects

- [excel-cleaner](https://github.com/jaxxcode-dev/excel-cleaner): cleans up messy Excel and CSV files. Removes duplicates and empty rows, and fixes mixed date and number formats.
- [scraper-demo](https://github.com/jaxxcode-dev/scraper-demo): collects book data from a practice website and saves it as CSV or Excel. The same approach works for product lists and prices on other sites.
